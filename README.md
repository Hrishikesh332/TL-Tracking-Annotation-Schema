# Pegasus 1.5 Video Analysis Tracking and Annotation Schemas

These schemas define how Pegasus should segment video and describe visible actions, procedure stages, object interactions, and changes over time. They support fixed-camera field-service footage, human-worn cameras, and robot-mounted cameras.

| File | Purpose |
|---|---|
| `annotation_fixed_cctv.json` | Annotate worksite activity, equipment interactions, visible states, and review cues from fixed cameras. |
| `annotation_egocentric_wearer.json` | Describe wearer actions, hand–object relationships, task objects, and visible changes from first-person footage. |
| `annotation_robot_egocentric.json` | Describe robot motion, end-effector interactions, gripper configuration, and task-object changes. |
